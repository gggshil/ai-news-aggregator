# Logo Assets Directory

Place your custom logo files in this folder:

1. **`navbar_logo.png`** (Transparent / No Background):
   - Used in the top navigation bar and headers.
   - Recommended format: PNG with transparent background.

2. **`app_logo.png`** (With Background):
   - Used for app icon / launcher / splash screens.
   - Recommended format: PNG (e.g. 512x512).
